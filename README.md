# Solar Cycle 25 Forecasting Using Machine and Deep Learning

## Research Overview

This repository contains the computational research undertaken as part of my MSc Data Science dissertation at Cardiff Metropolitan University, United Kingdom, completed in September 2024.

## Dissertation Title

A Comparative Study of Machine and Deep Learning Algorithms in Predicting Solar Cycle 25 Using Sunspot Number Data

## Research Objectives

- Investigate the application of machine learning and deep learning algorithms to solar activity forecasting.
- Analyse historical sunspot number data and identify temporal patterns.
- Compare the predictive performance of different computational models.
- Evaluate model generalisation, strengths and limitations across different forecasting periods.

## Dataset

The research uses historical sunspot number data and solar cycle minima and maxima data.

## Methodology

- Data preprocessing
- Exploratory data analysis
- Time-series analysis
- Model development and training
- Hyperparameter tuning
- Comparative performance evaluation
- Data visualisation

## Machine Learning and Deep Learning Models

- Long Short-Term Memory (LSTM)
- Convolutional Neural Network (CNN)
- Extreme Gradient Boosting (XGBoost)

## Key Findings

- LSTM demonstrated strong short-term forecasting potential but faced challenges in extended predictions.
- CNN demonstrated consistent performance in capturing cyclical patterns.
- XGBoost provided competitive results, although its performance varied depending on data complexity.
- The findings suggest that hybrid modelling approaches may improve forecasting robustness and accuracy.
